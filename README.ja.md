# Nescafe Barista Brew App

**ネスカフェのコーヒーマシンを、Bluetoothでシンプル・快適に操作できるカスタムアプリ。**（非公式）

カスタムレシピ、カスタムドリンク、お気に入りに対応したネスカフェ バリスタ用のカスタムアプリ。公式アプリの代わりに使えます。

[English → README.md](README.md)

## なぜ作ったのか

私は毎日ネスカフェ ゴールドブレンド バリスタを使っていますが、公式アプリには不具合が多く、しばらくすると勝手にログアウトされてしまいました。コーヒーを1杯淹れるたびに、ログインと再接続をやり直す毎日でした。

そこで、自分で作ることにしました。Nescafe Barista Brew App はマシンと Bluetooth で直接つながります。アカウントもログインもクラウドも不要。アプリを開いて「接続」をタップするだけで、コーヒーが淹れられます。

> **ネスカフェの皆さん、もしこのリポジトリを見ていたら：** デザインもアプリ開発も、ぜひ私に任せてください。もっと良いアプリを作ります（笑）
> **hello@aakashmehra.com**

## 主な機能

- **ワンタップ接続**：近くのマシンを自動で検出。ペアリングは最初の1回だけで、次回からは自動で再接続します。
- **アカウント・ログイン不要**：データはすべてスマホの中だけに保存されます。
- **カスタムレシピ**：濃さ・お湯の量・ミルクフォームの量を自由にカスタムできます。
- **お気に入り**：自分好みの設定に名前を付けて保存し、ワンタップで抽出できます。
- **ドリンクごとの作り方ガイド**：お湯やミルクの量、使うカプセルを確認できます。
- **マシンとカップのアニメーション**：白黒を基調としたシンプルなデザイン、Inter フォント、iOS の Liquid Glass に対応しています。
- **12種類のアプリアイコン**：設定画面から好きなものを選べます。
- **ライト／ダークモード**に対応しています。

## ⚠️「お湯のみ」モードはおすすめしません

多くのバリスタは、お湯だけを出すことができません。どの抽出プログラムでもコーヒーが入ってしまうためです。バリスタ W など一部の機種では、Nescafe Barista Brew App は **すすぎ（リンス）機能** を使ってお湯を出します。最初に1回セットアップをすると、量の目安を計算できます。ただし、量はあくまで目安で、温度も設定できない回避策です。**おすすめはしません。**

## インストール

### TestFlight
**近日公開予定。**

### IPA をサイドロードする
[Releases](../../releases) から `NescafeBaristaBrew.ipa` をダウンロードし、[AltStore](https://altstore.io) または [Sideloadly](https://sideloadly.io) を使ってご自身の Apple ID でインストールしてください。IPA は未署名のため、これらのツールがあなたの端末用に署名します。無料の Apple ID の場合、7日ごとに更新が必要です。

### ソースからビルドする
Xcode と Node.js がインストールされた Mac が必要です。

```bash
git clone https://github.com/aakashmehra/nescafe-barista-brew-app.git
cd nescafe-barista-brew-app
npm install
npx expo run:ios --device
```

> **Expo Go**（`npx expo start`）でも起動できますが、Expo Go では Bluetooth が使えないため、仮想マシンを使った **デモモード** になります。

## 使い方

1. **マシンの電源を入れ**、スマホを近くに置きます。
2. Nescafe Barista Brew App を開いて **「接続」** をタップし、一覧からマシンを選びます。
3. **初回のみペアリング：**
   - **バリスタ：** 電源ボタンでマシンを **オフ** にします（コンセントは抜かないでください）。ボタンが **緑色** に光ったら、約5秒以内に押してください。
   - **ドルチェ グスト：** マシンの電源を切り、ランプが点滅している間に抽出ボタンを押します。
4. ドリンクを選び、**濃さ・お湯・ミルク** を調整して **「抽出」** をタップします。
5. **★** でお気に入りに保存、**ⓘ** で作り方を確認できます。
6. **設定**（歯車アイコン）：アプリアイコンの変更、接続の解除、マシンの登録削除ができます。

一度ペアリングすれば、次回からはアプリを開くだけで自動的に再接続されます。
